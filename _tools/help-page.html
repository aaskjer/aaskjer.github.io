Which Streamer.bot version each project needs

Every project is an import string exported from Streamer.bot. Last exported from is the Streamer.bot version the project was last built and tested in, and Needs is the oldest version it runs in: Streamer.bot compiles the project's C# code on import, and a version older than that cannot compile it. Any version from Needs on imports it fine.

{{compat}}
