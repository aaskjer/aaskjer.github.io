Privacy

What happens to your data here

This site shows my Streamer.bot extensions. It has no accounts, no forms, no ads and no cookies. This page explains which services see your visit and what they keep.

Who is responsible

aaskjer (github.com/aaskjer), email: milianoids@zoho.eu. For questions about this page or your data, write to that address or open an issue in the repository of this site.

Hosting: GitHub Pages

The site is hosted by GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. To deliver the pages, GitHub receives your IP address and the usual request data (page, time, browser), and logs the IP address for security purposes. GitHub takes part in the EU–U.S. Data Privacy Framework. Details are in GitHub's privacy statement.

Legal basis: Art. 6(1)(f) GDPR, my legitimate interest in publishing this site reliably and securely.

Visitor statistics: Umami

To see how many people visit and what they use, the site counts visits with Umami Cloud, a service of Umami Software, Inc., 28 Geary St, Suite 650 #243, San Francisco, CA, USA. The statistics are stored in Umami's EU data region. Umami works with ClickHouse (EU/USA), Hetzner (EU) and Vercel (USA), which also loads Umami's counting script; transfers outside the EU are covered by the EU Standard Contractual Clauses in Umami's data processing agreement.

When a page opens, or when you click one of the buttons or links on it (for example a project's Download button), your browser sends Umami:

  • the address of the page, or the name of the button you clicked and the project it belongs to,
  • the page you came from (referrer),
  • your screen size and browser language.

From the request Umami works out your browser, operating system, device type and approximate location. To group several page views into one visit, it computes an anonymous visit ID from your IP address, your browser details and a regularly changing random value, without cookies. Umami states that it stores nothing that identifies you personally; I only see totals, such as “12 visits from Discord today” or “30 clicks on Download for Trivia Game”. No cookies and no other storage in your browser are used. The statistics are kept for six months. See Umami's privacy policy.

Legal basis: Art. 6(1)(f) GDPR, my legitimate interest in knowing how the site is used, so I can improve it.

Project numbers and documents from GitHub

The stars, downloads, version numbers and update dates on the project cards and project pages are loaded live by your browser from GitHub's public API (api.github.com), so GitHub also receives your IP address for these requests. To pick the projects in the Featured box, the start page also loads the daily download counts of the projects from this site's own repository on GitHub (raw.githubusercontent.com). The answer from the API is kept in your browser's local storage for one hour, so a reload does not ask GitHub again. Local storage also remembers whether you picked the light or dark theme, and when you last opened the site, so releases published since then can be marked “New”. All of this stays in your browser and are never sent anywhere; you can delete them at any time in your browser settings.

Each project's own page (for example Blackjack Game) shows the documents from that project's GitHub repository, such as its README, setup guide and FAQ. Your browser loads them, and any pictures in them, straight from GitHub (raw.githubusercontent.com, github.com and GitHub's image storage, which runs on Amazon Web Services), so GitHub receives your IP address for these requests too. GitHub's privacy statement applies.

Legal basis: Art. 6(1)(f) GDPR, my legitimate interest in showing current numbers and the projects' current documentation.

Store links from GameCheck

The Discord messages of GameCheck can link a game through aaskjer.github.io/go/, because Discord only opens web links. That page reads the store and the game from its own address and opens the game in Steam or the Epic Games Launcher on your computer. It counts nothing, stores nothing and sends nothing anywhere; Umami is not loaded on it. GitHub Pages delivers it like every page here (see Hosting above).

Links to other sites

The site links to GitHub, Twitch, Discord and Streamer.bot. Once you follow such a link, the privacy policy of that site applies.

Your rights

Under the GDPR you can ask for access to the data about you (Art. 15), its correction (Art. 16) or deletion (Art. 17), restrict its processing (Art. 18) and object to it (Art. 21). You can also complain to a data protection supervisory authority (Art. 77). Neither this site nor its statistics keep data that identifies you, so there is usually nothing to look up, but feel free to ask.
