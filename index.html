Get started

Every extension installs the same way.

  1. 1

    Grab it

    Download the .sb file from the project's latest release, or copy its import string.

  2. 2

    Import it

    Click Import in Streamer.bot, drop the file in or paste the string, and confirm.

  3. 3

    Make it yours

    Enable the commands, open the settings window and follow the project's setup guide.
